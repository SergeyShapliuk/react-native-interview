## Ключевая формулировка урока

**JavaScript использует pass-by-value. При передаче объекта значением является ссылка на объект.**

Это не придирка к словам: из неточной формулировки «объекты передаются по ссылке» следуют неверные предсказания — например, что переприсваивание параметра внутри функции изменит переменную вызывающего. Разбор — в theory.md, угол 2.
