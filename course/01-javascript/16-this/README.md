> 🟡-урок: разбор по семи углам — что это · как работает · почему важно · где в React Native · типичные ошибки · trade-offs · связи с другими частями системы.

## Цель

Определять значение `this` в любом вызове — и понимать, что в современном functional React/RN эта тема нужна **в основном для чтения чужого кода**, а не для написания своего.

## Что внутри

Четыре правила определения `this` (обычный вызов, вызов методом, `new`, явная привязка) · стрелочные функции и лексический `this` · `bind` / `call` / `apply` · потеря `this` при передаче метода как колбэка · ошибки: передача метода без привязки, `bind` в рендере, стрелочное свойство класса и его цена · trade-off: стрелочные методы удобны, но создаются на каждый экземпляр.

## Честная рамка урока

**Этот урок не предлагает использовать `this` в новом коде.** В функциональных компонентах, хуках и чистых функциях — то есть в основной массе кода современного RN-приложения — `this` не нужен, и специально искать ему применение не надо. Хук не имеет `this`, замыкание (1.14) решает ту же задачу явно.

Тема нужна там, где `this` приходит извне: классовые сервисы и доменные модели, классы ошибок, классовые компоненты в проектах с историей, API библиотек на классах, обёртки нативных модулей и emitter-ы, методы объектов, переданные обработчиками. Полный разбор — в theory.md, угол 4.
