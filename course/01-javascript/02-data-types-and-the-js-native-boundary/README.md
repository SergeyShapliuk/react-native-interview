## Цель

Знать, какие значения существуют в JavaScript и какие из них в принципе способны пересечь границу между JS и нативным слоем.

## Что внутри

Примитивы и объекты · `undefined` vs `null` · `NaN` · `Symbol` и `BigInt` и почему их почти не видно в RN-коде · `typeof` и его ловушки · сериализуемость как свойство значения.

> **Границы урока.** Здесь разбирается только то, какие **значения** способны пересечь границу JS↔native. Как устроена сама граница — предмет блока 04: современный RN использует JSI, где возможны синхронные вызовы и работа с нативными объектами по ссылке. Формулировок вида «JS сериализует всё в JSON и отправляет в native» в этом уроке нет и быть не должно.
