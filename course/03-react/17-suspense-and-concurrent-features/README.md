## Что внутри

Lanes и приоритеты: что делает обновление срочным или несрочным · `startTransition` / `useTransition` и `isPending` · `useDeferredValue` — отложенная копия значения · time slicing: уступка потока между компонентами, но не внутри одного · прерванная и выброшенная работа · Suspense: приостановка, ближайшая граница, fallback и его троттлинг · `use(promise)` и требование кэшировать промис · переход не прячет уже показанное содержимое за fallback · `<Activity>` (React 19.2): скрытое поддерево с сохранённым состоянием и отключёнными эффектами · где в RN: только New Architecture; поиск по длинному списку, тяжёлые табы; предел — commit и нативная сторона не прерываются · trade-offs: отзывчивость против сложности модели.

## Ключевая формулировка урока

**Concurrent rendering — это не параллельность, а право React бросить начатый рендер ради более срочного. Отсюда новая гарантия (интерфейс отвечает) и новая цена (рендер может не дойти до экрана, и компонент обязан это переживать).**
