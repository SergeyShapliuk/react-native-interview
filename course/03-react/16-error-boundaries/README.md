## Цель

## Что внутри

Классовый компонент с `getDerivedStateFromError` и `componentDidCatch` · что ловится: рендер, синхронные тела эффектов и их очисток · что не ловится: обработчики событий, таймеры, продолжения после `await`, верхний уровень модуля, ошибки самой границы · как довести асинхронную ошибку до границы · что происходит без границы: React очищает весь корень · `onCaughtError` / `onUncaughtError` и как их использует RN 0.87: непойманная ошибка рендера — фатальная · расстановка границ: корень, экран, независимые виджеты · сброс границы ключом · где в RN: пустой экран против рабочей навигации, LogBox в dev.

## Ключевая формулировка урока

**Error Boundary ловит ошибки, брошенные, когда React сам выполняет ваш код: рендер, методы жизненного цикла, синхронное тело эффектов и их очисток. Всё, что вызывает рантайм, — обработчики, таймеры, продолжения промисов — проходит мимо.**
