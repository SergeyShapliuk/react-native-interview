## Цель

Выводить правила хуков из того, как React хранит состояние, и писать массив зависимостей, который не врёт.

## Что внутри

Хуки как список на fiber и почему React узнаёт хук по номеру вызова · два правила хуков и что ломает их нарушение · массив зависимостей: поэлементное `Object.is`, отсутствие массива, `[]` · «честный» массив: всё реактивное, что читает эффект · что указывать не нужно · пять способов уменьшить зависимости, не соврав: функциональное обновление, функция внутри эффекта или вне компонента, примитив вместо объекта, `useEffectEvent` (React 19.2) · `eslint-plugin-react-hooks` 7 и почему его предупреждение не глушат · `async` в эффекте · trade-offs: перезапуск, ref или `useEffectEvent` — снимок или актуальное значение.

## Ключевая формулировка урока

**React узнаёт хук по порядковому номеру вызова, а не по имени. Массив зависимостей — не список «когда перезапускать», а перечень всех значений из рендера, которые эффект читает.**
