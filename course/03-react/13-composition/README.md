## Что внутри

Почему пропс пробрасывается через три уровня: дерево собрано не там, где данные · `children` как способ не знать о содержимом и почему элементы `children` не рендерятся при изменении состояния обёртки · слоты: несколько пропсов-элементов · render props: когда содержимое зависит от состояния контейнера, и что из этого закрыли хуки · compound components: неявный контракт через локальный контекст · HOC: читать уметь, новый код писать иначе · где в RN: обёртки экранов, layout-компоненты, дизайн-система, анимированная шапка · ошибки: Context вместо композиции, `cloneElement`, `memo` на обёртке с `children`.

## Ключевая формулировка урока

**Пропс пробрасывается через три уровня не потому, что нужно глобальное состояние, а потому, что дерево собрано не в том месте. Элемент, созданный там, где данные уже есть, никуда их не пробрасывает.**
