## Что внутри

Где источник истины: состояние React или нативное поле · controlled: `value` + `onChangeText`, полный круг через рендер на каждый символ · uncontrolled: `defaultValue`, значение в ref по `onChangeText`, сброс ключом или `clear()` · как `TextInput` в RN 0.87 синхронизирует значение из JS с нативным полем и почему изменение значения в JS даёт мерцание · цена controlled на большом экране и как её снижать: состояние ближе к полю, `memo` на строках, деление формы · где uncontrolled не справляется: маска, зависимые поля, валидация на лету · библиотеки форм как выбор режима · ошибки: вся форма в состоянии корня, форматирование в `onChangeText`, `defaultValue` как способ обновлять поле.

## Ключевая формулировка урока

**В controlled-форме источник истины — состояние React, и каждый символ проходит полный круг через рендер. В uncontrolled — источник истины нативное поле, и React узнаёт значение, только когда спросит или когда ему сообщат.**
