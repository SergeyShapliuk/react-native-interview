## Цель

Параметризовать функцию или тип так, чтобы связь между входом и выходом сохранялась, и видеть случаи, когда параметр типа ничего не связывает.

## Материалы урока

- [theory.md](./theory.md) — refresh и RN relevance
- [practice.md](./practice.md) — проверка понимания и задание

## Что внутри

Параметр типа как переменная уровня типов · вывод параметра из аргумента и когда его приходится указывать явно · `extends` как constraint, а не наследование · значение параметра по умолчанию · generic-функция против generic-типа · несколько параметров и связь между ними · `keyof T` в ограничении и доступ `T[K]` · признак лишнего generic: параметр типа встречается в сигнатуре один раз.
